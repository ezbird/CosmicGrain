# CosmicGrain

A live dust physics module for [Gadget-4](https://wwwmpa.mpa-garching.mpg.de/gadget4/), implementing explicit N-body dust superparticles (PartType6) in cosmological zoom simulations.

## Overview

CosmicGrain models the full lifecycle of interstellar dust grains alongside gas dynamics in a MW-mass zoom simulation (Halo 569, 50 Mpc box). Dust superparticles are spawned from stellar feedback events and evolved through:

- **Creation**: SNII (10 nm silicate, f_C=0.1) and AGB (100 nm carbon, f_C=0.6) channels
- **Gas-dust drag**: Epstein regime aerodynamic coupling
- **Thermal sputtering**: McKinnon+2017 timescale, composition-dependent sublimation
- **SN shock destruction**: Sedov-Taylor framework, Bocchio+2014 efficiency curves
- **ISM grain growth**: Hirashita & Kuo 2011 with subgrid clumping factor
- **Coagulation and shattering**: density-dependent collisional processes
- **Radiation pressure**: grain-mass-weighted force coupling
- **Astration**: dust consumption during star formation

## Simulation

| Property | Value |
|---|---|
| Box size | 50 Mpc comoving |
| Primary resolution | 1024³ |
| Halo | Halo 569, MW-mass zoom |
| M200 | ~1.6×10¹¹ M☉ (M_Crit200) |
| R200 | 114.7 pkpc at z=0 |
| Cosmology | Planck 2015 (h=0.6732, Ω_m=0.3158) |

## Physics Ladder

Runs S0–S10 activate dust processes cumulatively:

| Run | Physics added |
|---|---|
| S0 | Dust creation only |
| S1 | + Dust cooling |
| S2 | + Gas-dust drag |
| S3 | + Astration |
| S4 | + Thermal sputtering |
| S5 | + ISM grain growth |
| S6 | + Subgrid clumping |
| S7 | + SN shock destruction |
| S8 | + Coagulation |
| S9 | + Shattering |
| S10 | + Radiation pressure (full model) |

## Status

Primary 1024³ physics ladder in progress. Key results:
- Bimodal grain size distribution with peaks at ~10 nm (SNII silicate) and ~100 nm (AGB carbon)
- ISM slope α = −3.48 ± 0.21
- Aerodynamic decoupling confirmed: large grains retained in ISM, small grains entrained in outflows
- Radiation pressure null result at MW-mass zoom resolution
