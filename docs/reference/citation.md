# Citation

CosmicGrain does not currently have a dedicated software DOI or published
code paper. When using the code, identify the exact CosmicGrain version or
commit and cite the repository:

> CosmicGrain, [version or commit], https://github.com/ezbird/CosmicGrain

Also cite the GADGET-4 method paper:

> Springel, V., et al. (2021). *Simulating cosmic structure formation with
> the GADGET-4 code*. Monthly Notices of the Royal Astronomical Society, 506,
> 2871–2949. https://doi.org/10.1093/mnras/stab1855

Cite the primary literature for the dust prescriptions used in the analysis;
the relevant references are listed on each [Dust Physics](../physics/index.md)
page. A dedicated software citation will be added if a DOI or formal code
paper becomes available.
