# Citation

A formal CosmicGrain software citation will be added with the public code/paper release. Until then, publications using CosmicGrain should identify the code as a GADGET-4-based dust simulation code and cite the underlying GADGET-4 method/software literature as appropriate.

When a versioned CosmicGrain release, DOI, or primary methods paper is available, this page should be updated before public release so users have one unambiguous citation instruction.
