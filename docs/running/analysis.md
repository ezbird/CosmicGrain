# Analysis Entry Point

The maintained analysis guide now lives in the dedicated
[Analysis](../analysis/index.md) section. It covers snapshot conventions,
halo catalogs, shared Python utilities, dust distributions, radial profiles,
extinction/\(R_V\), conservation diagnostics, and SKIRT exports.

Run scripts from `scripts/` unless their `--help` text states otherwise, so
`halo_utils.py` and `cosmicgrain.mplstyle` resolve
consistently.
